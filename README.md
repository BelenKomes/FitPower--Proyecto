# FitPower

## Descripción

Diseño del sitio web para el gimnasio "FitPower". La versión actual incluye la landing page y la página de login.

## Instalación

Para instalar el programa de forma rápida, se puede clonar el repositorio. Una forma sencilla de hacerlo es ejecutando el comando `git clone` en la terminal (es necesario tener git instalado).

```bash
git clone https://github.com/BelenKomes/FitPower--Proyecto
```

Si el comando se ejecutó con éxito, los archivos del repositorio deberían estar en una carpeta de nombre "FitPower--Proyecto", ubicada en el directorio en el que el comando fue ejecutado.
